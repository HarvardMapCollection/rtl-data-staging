old_harvard_yard_photos.geojson is the data file that powers the interactive map project, [Old Harvard Yard](https://felt.com/map/Old-Harvard-Yard-lxyv4F5eQ79Bz9AeXW1wcnoD?loc=42.374268,-71.116861,18.31z).

This is a point dataset showing locations in Harvard Yard. Each location links to both a historical image of the location found in the Harvard Library digital collections, as well as a modern photo taken by the students who created by the project.

The purpose of this project was to understand more about the history of the built and natural environment of Harvard Yard, to study it through the lens of potential environmental rewilding, as this was for a course titled, Rewilding Harvard, taught by Joyce Chaplin. This data, however, can be used for anyone looking for photographs showing then and now in Harvard Yard.

To read more about the project, see interactive maps and photos, and learn about Harvard Library’s role in supporting the project, visit the [project write-up](https://mapping.share.library.harvard.edu/posts/re-wilding-2024/) on the Harvard Map Collection GIS blog and tutorial site.
